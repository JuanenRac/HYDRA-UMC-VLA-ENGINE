## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

In a VLA-driven system, a compromised model can translate safe intentions into dangerous actions. If you discover a vulnerability affecting the **action token integrity**, **model weight tampering**, or **vision-language hijacking**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe if the bug allows generating unauthorized robot movements, bypassing motion limits, or injecting malicious commands via text inputs.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy to ensure hardware safety before public release.
